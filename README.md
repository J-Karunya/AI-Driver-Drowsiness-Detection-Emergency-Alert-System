An Advanced Driver Assistance System (ADAS) built for real-time inference on live webcam feeds. This system uses a hybrid approach—combining traditional Computer Vision algorithms with Deep Learning sequence models—to accurately detect driver fatigue and distraction. 

This project demonstrates core competencies required by top automotive AI companies (e.g., Bosch, Mobileye, Tesla) for in-cabin monitoring systems.

---

## ✨ Key Features

### 1. Dual-Layer Drowsiness Detection
*   **Rule-Based Backbone**: Utilizes **MediaPipe Face Mesh** (468 3D landmarks) to calculate the Eye Aspect Ratio (EAR) and Mouth Aspect Ratio (MAR) per frame. Instantly triggers alerts if values cross dynamic thresholds (catching sudden yawning or eye closure).
*   **Deep Learning Sequence Model**: Extracts 30-frame temporal sequences of EAR/MAR and feeds them into a custom **PyTorch LSTM** neural network trained on the UTA-RLDD dataset. This secondary layer successfully catches the gradual onset of micro-sleeps and fatigue that simple threshold logic often misses.

### 2. Distraction Detection
*   **Head Pose Estimation (Looking Away)**: Computes the driver's Head Pitch, Yaw, and Roll using the Perspective-n-Point (PnP) mathematical algorithm by matching MediaPipe's 2D facial landmarks to a standard 3D face model.
*   **Object Detection (Phone Usage)**: Runs **YOLOv8** (Nano) concurrently on the video feed to detect if the driver is holding a cell phone near their face or steering wheel.

### 3. Real-Time Web Deployment
*   Fully deployed via a **Streamlit** web application.
*   Uses `streamlit-webrtc` for zero-latency, secure in-browser video streaming directly to the local Python backend.
*   Fully **GPU-accelerated** (CUDA) for both YOLOv8 object detection and PyTorch LSTM inference.

## 📊 Dataset

The PyTorch LSTM is trained on the **UTA-RLDD (University of Texas at Arlington Real-Life Drowsiness Dataset)**. It contains diverse, real-world videos of subjects in varying states of alertness (Alert, Low Vigilance, Drowsy).

## 🚀 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone <repository_url>
   cd "Real-Time Driver Drowsiness & Distraction Detection"
   ```

2. **Set up the Conda Environment:**
   It is highly recommended to use an environment with CUDA configured.
   ```bash
   conda create -n myenv python=3.10
   conda activate myenv
   ```

3. **Install Dependencies:**
   ```bash
   pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
   pip install opencv-python mediapipe ultralytics streamlit streamlit-webrtc scipy numpy
   ```

## 💻 Usage

### 1. Run the Live Web App
Launch the Streamlit ADAS dashboard:
```bash
conda activate myenv
streamlit run app.py
```
*   Grant your browser permission to access the webcam.
*   Use the sidebar to adjust EAR, MAR, and Head Pose thresholds dynamically.
*   Test the system by closing your eyes, looking sharply to the side, or holding up a smartphone!

### 2. Train the LSTM Model (Optional)
If you want to re-train the PyTorch LSTM on the raw UTA-RLDD video dataset (`Fold1_part1`):
```bash
conda activate myenv
python train_lstm.py
```
This script will iterate through the `.mov` files, extract EAR/MAR sequences, train the network, and output a new `drowsiness_lstm.pt` weights file.

## 📁 Project Structure

```text

├── drowsiness_lstm.pt      # Custom LSTM weights (generated by train script)
```
